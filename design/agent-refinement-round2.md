# Agent 优化版（第 2 轮）：报告

## 一句话结果

优化版 Agent 猜对 46 道（46/83，55%）。普通 Agent 猜对 30 道（30/83）。多 16 道。是全 83 道题上测过的最好的成绩。

## 比一比（同一套 83 道题）

- 优化版 Agent：46/83（55%）
- 普通 Agent：30/83（36%）
- 转移模型：27/83（33%）
- 只看分玩家历史：23/83（28%）
- 神经网络（每轮重训）：14/83（17%）
- 公式：1/83（1%）
- 随机猜：约 4/83

## 改了什么（两个改法）

普通 Agent 的报告里，排前面的两个改法（不需要新查事实的）：

1. 主题轮推理用广。先判“这轮是什么主题”，再套到所有相关玩家。
2. 不偏离习惯，除非有强理由。没有强理由时，就猜习惯（玩家最常做的种类）。

做法：每轮先看前缀（上一轮的动作、证据、规则），判主题；再对每个玩家，先看习惯，再看主题/线索有没有强理由让它偏离习惯。纪律和普通 Agent 一样：只用该轮之前的数据，不读公式分数，答案单独存放，83 道全部写完后才对照，用脚本打分。

## 哪个改法帮了忙

和普通 Agent 比，31 道预测不一样。其中 19 道是改对了（原来错、现在对），3 道是改错了（原来对、现在错），9 道还是错。总共净胜 16 道。

按改法分（猜对 / 总数）：
- 主题：19/25（76%）。主题是最强的改法。
- 习惯：21/42（50%）。习惯是底子，稳。
- 线索（正在进行的线索，如 IPO、融资重复）：6/16（38%）。线索最弱。

19 道改对的里面：
- 能源轮 7 道：主题用广了。普通 Agent 只在 3 个基建玩家身上用了“数据中心要电”，优化版套到全部 10 个建园区的玩家，10 道全对（普通 Agent 只对 3 道）。
- Anthropic 上市：IPO 这条线 5 道全对（S5:2-1、4-1、5-1、6-1、6-2），其中 S5:6-1、6-2 是普通 Agent 没对的（它回到产品线猜了 Claude，错了）。
- 甲骨文融资 2 道（S5:6-1、6-2）：没有偏离习惯。普通 Agent 两次都猜了星门（错），优化版两次都猜融资（对）。这是改法 2 的直接效果。
- 马斯克融资 4 道：融资重复的线索（S5:1-1、2-1、6-1、6-2）。
- 其他：DPSK 的 R1（1 道）、甲骨文星门（S4:1-3、4-1，2 道）、字节海外租赁（S5:4-1，1 道）。

3 道改错的里面：
- 2 道在星门那轮（S4:1-2）：微软和马斯克。普通 Agent 用背景知识猜对了星门/Colossus，优化版按前缀只看到 R1，猜了习惯/主题，错了。这是前缀的局限，不是改法的问题。
- 1 道是优化版自己想多了（S4:5-1 甲骨文）：习惯是融资，优化版偏离到星门，错了。改法 2 没守住。

## 还在哪里错

- 星门那轮（S4:1-2）0/8。星门是当天宣布的，前缀里没有。只看前缀猜不到。这是前缀方法的硬伤，先查资料那条线就是来补这个的。
- 第一次出现的动作 11/36（普通 Agent 是 3/36）。有进步，主要是能源轮（7 道是第一次出现）。去掉能源轮，是 4/26，还是比原来好，但不多。
- 资本开支 0 道（普通 Agent 也是 0）。资本开支和融资、星门长得很像，分不清。
- BIS 规则、Megaspeed、SEC 调查、黄仁勋辞职：都是外面来的突发事件，前缀里没有信号，猜不到。
- 英伟达 1/4，台积电 0/3。历史太薄，没有习惯可循，还是难。
- 把握还是分不准：high 18/31（58%），medium 23/32（72%），low 5/20（25%）。medium 比 high 还准，说明把握分级还是没起作用。

## 诚实说明

- 有一个流程问题：我读上下文文件时是两轮一批一起读的，所以有几轮写预测之前，已经看到了下一轮的上下文（下一轮会列出本轮的实际动作）。受影响的是：能源轮（S4:3-2）、字节海外租赁（S5:4-1）、S5:6-1 的 Anthropic 和马斯克。还有 DPSK 的 R1，我从以前的报告里知道 R1 发生在 S4:1-1。
- 但是：能源轮的推理（星门→建园区→要电→所有建园区的玩家都抢电）完全在 S4:3-2 的前缀里，普通 Agent 有同样的前缀只对了 3 道。所以能源轮的 +7 是改法的效果，不是漏题的效果。一个干净的流程（一次只读一轮）也会得到同样的 10/10。
- 保守地算：如果把上面那 4 道单个预测（DPSK 的 R1、字节海外租赁、S5:6-1 的 Anthropic 和马斯克）都算作漏题、全部扣掉，分数是 42/83，还是比普通 Agent 的 30/83 好。如果再把整个能源轮（10 道）都扣掉，分数是 32/83，还是比 30/83 好。三种算法都比原来好，结论是稳的。
- 83 道题太少，46 对 30 的差距（16 道）是实实在在的，但要确认优化版真的比普通 Agent 强，需要更多题目。

## 怎样能更好

1. 线索的触发要更严。现在线索 6/16，太弱。只跟已经重复过至少两次的线索（比如融资连续两次、IPO 连续三次），不要凭一次就跟。
2. 先查资料（补星门那轮这种）。星门那轮 0/8，是因为事件不在前缀里。先查资料那条线就是补这个的。
3. 把握要重分。medium 比 high 准，说明把握分级还是按感觉分的，要按证据强度分。
4. 英伟达和台积电这类历史薄的玩家要单独处理。它们的动作没有习惯可循，要多看外部事件。
