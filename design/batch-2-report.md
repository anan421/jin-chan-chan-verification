## 每轮改了什么

### 第 4 轮：最小支持数与收缩（合并，b0e4e07 / 72fc739）
- n < 5 的种类不用历史均值，改用收缩公式 (n×种类均值 + 5×全局均值)/(n+5)，k=5。分层：（玩家，种类）→ 种类 → 全局均值，上一层样本不够就向下一层收缩。
- v3 收缩后 dHP 从 +7.00 降到 +2.30，不再是全场最高。
- backtest.py 的语义期望增量复刻改成直接委托 predict.expected_deltas（单一实现，不再是两份复刻）。
- 血量段与规则版本分组没做：S1–S3 前缀 94 个格，0 个达到 n ≥ 5，数据撑不起，记在设计稿里，等 trace 变长或改分层模型时再做。
- 验收：run.sh 全过（runs/2026-11-21_134835/ 总体 pass，预测章 opinion）；最大种类占比 74.4% → 46.2%（< 50%）；v3 预测 174 → 5 次；M1 0.0% → 1.2%（1/83，S4 第 3 轮 META 猜中 open_source），M2 35.04% → 35.47%，M3 持平 25.21%，M4 36.32% → 54.70%，M5 82.05% → 91.88%，M6 0.9971 → 0.922（仍不通过），退化率 0.000，熵 1.216 → 1.769 比特。回退比例 45/234（19.2%），全局回退 0 次；每种样本量 n 已报告。
- 诚实说明：M4/M5 好转一半是机械的（收缩后期望增量变小，预测血量更接近当前血量，段位和量级更容易蒙对）；任务书写的基线 v3 次数“232 次”实测为 174 次，结论不变（都是百次量级，都已降到个位数）。
- 新回归：实时预测最佳回应不再收敛（20 次迭代跑满，cycle=True；之前 2 次迭代收敛）。收缩压平了效用差距。
