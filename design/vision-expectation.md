# 愿景与期望（2026-11-22）

## 愿景
预测员像一个好的金铲铲玩家一样读局：看组合、看时机、看对手、看经济。预测的不只是一个种类标签，而是这一轮的故事。分数要诚实量出来（选和估分开），弱项不藏着。

## 期望（写下来，2026-11-22）
1. 题集重新设计：公开事件类，140 道以上（含 S6 新轮次），每道题都有明确的、可查的事实依据。内部状态类、标签不清的题，修掉或去掉。
2. 总分：猜中 80% 以上（112/140 以上）。
3. 诚实：这个分数是在没用来选方法的题集上量的。选方法用一套题，报分数用另一套题。
4. 弱项：每个种类、每个玩家、每个轮次的分项分数都报出来，最弱的一项不低于 50%。

为什么是 80%：老 83 道上，修日期（+4）、修边界（+2–3）、修台积电（+2），加起来约 68/83（82%）。80% 就是把这个顶推广到更大的题集上，并且用没选过方法的题集诚实量出来。如果新信号在没见过的题上也管用，80% 能达到；如果达不到，说明愿景本身有问题，复盘时改期望。

## 框架的问题（四层）
### 数据层
- 83 道题不是设计出来的，是分类覆盖的副产品。S4–S5 能分类的动作只有 83 道，就成了题集。题集没有目标数量、没有难度平衡、没有覆盖保证。23 道错题集中在几个类别里，就是题集不平衡的证据。
- 轮次是人工切的。一轮压了几周甚至几个月，轮次里的事件没有顺序。日期修正线已经证明了轮次日期和事件真实日期对不上（S4 1-1、S5 1-1、S5 3-2）。
- 种类标签是页面作者的叙事判断。有些是内部状态，不是公开动作。答案本身就是模型。
- 词汇是扩出来的，不是设计出来的。种类边界不清（Grok 4 算 SpaceX 还是 Colossus，文心 4.5 开源算文心还是开源）。

### 预测层
- 一个预测员猜所有 18 个玩家。没有分工。
- 预测员读的是摘要，不是全文。不读玩家自己说的下一步（前瞻指引），不读日历，不看钱，不看对手。
- 输出只有一个种类加一个把握分。没有分布，没有“我不知道”，没有可打分的推理。

### 评估层
- 没量过噪声。每条线只跑一次，1–2 道的差距就是噪声。
- 选和估没分开。同一套 83 道题既用来选赢家，又用来报赢家的分数。赢家的分数是虚高的（赢者诅咒）。
- 没按最弱一环打分。只看总分 60/83，藏着弱项（资本开支 2/5、台积电 0/3）。
- 题集是静态的。83 道题从来没长过。前沿实验室的做法是题集是活的（S6 新轮次加题）。

### 迭代层
- 锦标赛测的是方法，不是组件。好组件（日期修正 +4、台积电主题 2/3）没有自动变成新底子，只躺在报告里。
- 没有棘轮：赢一次锁死为新基线。这条前沿实验室有，我们没有。

## 为什么一直是 83 道题
因为 S4–S5 能分类的动作只有 83 道。S1–S3 是学用的，S4–S5 是考用的，能分类的才变成题。83 不是设计出来的数，是“词汇量只够分出 83 道”的结果。题集是继承来的，从来没设计过。

## 前沿实验室是怎么玩的（对照）
研究结论（design/how-frontier-labs-experiment.md）：先写 eval、选和估分开、先量噪声、配对比较、按最弱一环打分、失败先分类、多路共享日志、一个结论三路印证、eval 是活的。
我们做到的：配对比较、单轮隔离、失败分类、复盘写报告。
我们没做到的：量噪声（每条线只跑一次）、选和估分开（同一套题既选又估）、最弱一环打分（只看总分）、eval 是活的（题集从来没长过）。

## 真实的金铲铲比这个复杂在哪
1. 组合：金铲铲的强在羁绊和阵容，不在单个棋子。我们的任务一次只猜一个种类，但真实动作是组合——星门 + 能源 + 资本开支 + 融资，是一整个故事，分几轮、几个人讲完。猜对单个种类但没猜对组合，等于没读懂局。
2. 时机：什么时候出牌和出什么牌一样重要。IPO 赶在市场热的时候，资本开支跟在财报后，产品发布跟在发布会后。我们的任务不建模时机，只问“这轮做什么种类”。
3. 经济：金币管理是核心技术——什么时候存、什么时候花、什么时候抽。我们的任务里金币几乎没用（只用血量金币 50 道只对 4 道），但金币可能预测的是幅度和时机，不是种类。
4. 站位：排名靠后的玩家要搏，靠前的玩家要稳。我们的任务不用相对位置。
5. 随机：海克斯和选秀是随机的。有些事件就是随机的（泄露、突发丑闻、意外宣布），猜不到是正常的。
6. 对手互动：别人抢你要的棋子，你得换阵容。我们的任务里预测员看上一轮的动作，但不建模“争抢”（两个玩家要同一批芯片，一个拿到，另一个拿不到）。

我们的任务只抓住了 1.5 个维度（主题 = 弱组合，上一轮 = 弱对手互动）。

## 能达到期望的方法（按可能性排）
1. 重新设计题集（框架先行）：公开事件类，140 道以上，含 S6，修边界、修日期、选和估分开、量噪声。没有它，80% 的期望量不出来。这是基础设施，不是可选项。
2. 加前瞻指引（新信号）：玩家自己说的下一步（财报电话会、CEO 表态、S-1 文件）。最大的缺失信号，直接对着资本开支和产品发布去的。
3. 18 个 agent 各玩各的（新架构）：每个 agent 扮演一个玩家，各自有目标、约束、信息，互相看对方的动作。最大的结构变化。
4. 加日历 + 财务约束（新信号）：日历（财报日、发布会、监管截止日）最便宜；财务（现金、债务、资本开支指引）对着资本开支去的。
5. 换个问题（新任务）：预测下一个大事件（什么事件、什么时候、谁主导），或者预测赛季末排名，或者预测下一两轮的序列。最激进。
6. 量噪声 + 选和估分开（新评估）：每条线跑 3 次，报 spread；选方法用一套题，报分数用另一套题；按最弱一环打分。这是测量纪律，不是方法。

## 先做哪一条（第一个实验）
最有可能的一条：前瞻指引。
- 假设：缺失的信号是玩家自己说的下一步。加了前瞻指引，老 83 道上多对 5 道以上。
- 做法：建一份前瞻指引事实库（财报电话会里的指引、CEO 表态、S-1 文件、已宣布的计划，全部只用轮次日期之前的）。先查资料加这份输入，重跑老 83 道。单轮隔离，同一套纪律。
- 证伪：多对不到 3 道，说明前瞻指引不是缺失的信号，顶在别处（架构或任务）。丢掉这条，换下一条。
- 同时：把题集重设计（140 道、S6、选和估分开、量噪声）当作下一轮的基础设施。没有它，80% 的期望量不出来。

## 循环
假设 → 实验 → 复盘 → 验证 → 再循环。每轮只改一小处，复盘写成报告，下一轮从复盘定方向。不按预定计划走。
