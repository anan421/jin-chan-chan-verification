# Agent 预测原型：报告

## 一句话结果

Agent 猜对 30 道（30/83，36%）。公式猜对 1 道（1/83）。只看玩家历史的简单规则猜对 23 道（23/83）。Agent 比公式好 30 倍，比简单规则好 7 道。

## Agent 读什么

每猜一次，Agent 读一份上下文文件，只含猜的那个时间点之前的数据：

- 玩家现在的状态：血量、金币。
- 玩家过去做了什么：最近 3 次动作、最常做的动作种类及次数、累计血量和金币变化。
- 当前规则版本（及是否刚变）。
- 上一轮 18 名玩家的动作（对手刚做了什么）。
- 近期事实：之前两轮的证据条目（新闻、财报、公开表态）。
- 动作种类词汇表（31 种）。

Agent 不读公式的分数。不用自己“记得”的 2025–2026 年的事，只用给它的前缀。答案单独存放，83 道全部写完后才对照。

## Agent 输出什么

每道题输出三样东西：猜的动作种类、理由（一句话，plain 语言）、把握多大（high / medium / low）。

## 分数

- 总分：30/83（36.1%）。
- 公式：1/83（1.2%）。
- 只看玩家历史的简单规则：23/83（27.7%）。
- 只看全局最常见的种类：6/83（7.2%）。
- 随机猜：约 4.3%。

Agent 和简单规则的重合：20 道两边都对。Agent 独自对 10 道，简单规则独自对 3 道。净胜 7 道。

按轮次：最好的一轮是 S4:4-1（7/10，回到产品的那轮）。最差的是能源轮 S4:3-2（3/10）和 S5:3-2（1/5）、S5:6-1（1/5）。

按把握：high 8/21（38%），medium 14/36（39%），low 8/26（31%）。把握分得不太准——high 和 medium 差不多，low 只差一点。Agent 不太知道自己什么时候真的有把握。

## Agent 在哪里对

**重复的动作，Agent 很准（27/47，57%）。** 玩家以前做过的动作种类，Agent 猜对一半以上。产品类最准：开源 5/6、豆包 2/2、通义 2/2、文心 2/2、Gemini 1/1、Claude 1/1、混元 1/1、昇腾 1/1。玩家回到自己的主线产品时，Agent 基本能抓住。

**Agent 独自赢的 10 道，是它比简单规则强的地方：**

- 能源轮的三道（OAI、MSFT、MUSK）：Agent 从“大家在建数据中心，数据中心要电”推出能源，猜对 3 道。这是推理赢的，不是习惯赢的——能源是所有人第一次做的种类，简单规则不可能猜到。
- Anthropic 上市的三道（S5:2-1、S5:4-1、S5:5-1）：Agent 跟住了 IPO 这条线，连续三次猜对上市动作。
- 另外三道（MSFT 星门、MUSK 扩 Colossus、SFTB 星门、DPSK 开源）：Agent 跟住了正在进行的线索，而不是只看历史频率。

## Agent 在哪里错

**第一次出现的动作，Agent 几乎全错（3/36，8%）。** 83 道里有 36 道是该玩家第一次做这个种类，Agent 只对 3 道（就是上面那三道能源）。这是最大的短板。第一次出现的动作包括：

- R1（6 道）：Agent 一道也没猜。R1 是新模型冲击，前缀里没有玩家做过，Agent 想不到。
- BIS 规则（4 道）：Agent 一道也没猜。规则变化是外面来的，Agent 不读规则文本，只看动作历史。
- 资本开支（5 道）：Agent 猜了 3 次，全错。资本开支和融资、星门长得很像，Agent 分不清。
- 黄仁勋辞职、SEC 调查、Megaspeed（各 1 道）：都是外面来的突发事件，Agent 猜不到。
- 海外租赁（2 道）：Agent 猜了豆包两次，全错。字节要海外算力这条线，Agent 没跟住。

**能源轮漏了 7 道。** 能源轮 10 道里 9 道是能源，Agent 只猜了 3 个能源（全对），另外 7 个玩家它猜了产品（豆包、通义、昇腾、Claude、开源、融资、芯片）。Agent 只在基建玩家（OAI、MSFT、MUSK）身上用了“数据中心要电”这个推理，在产品玩家身上没用。推理是对的，但用得不够广。

**想多了，丢了 3 道。** 有 3 道简单规则猜对、Agent 猜错，全是 Agent 想多了、偏离了习惯：

- S4:5-1 的 OpenAI：实际是微软投资，Agent 猜了资本开支。
- S5:6-1 和 S5:6-2 的甲骨文：实际都是融资，Agent 两次都猜了星门（理由是“融资受挫，回到项目”——错了，甲骨文融资受挫后继续融资）。

**NVDA 全错（0/4），台积电全错（0/3）。** NVDA 的历史太薄（每种只做过 1 次），没有习惯可循；它的动作全是突发事件（合规质问、CEO 辞职、SEC 调查）。台积电的历史也薄，Agent 不知道代工厂该猜什么。

## 怎样能更好

按优先级：

1. **先查资料再推理。** 最大的短板是第一次出现的动作（36 道里只对 3 道）。这些动作大多是外面来的（新模型、新规则、突发事件）。Agent 现在只读前缀里的动作和两条事实，没有检索。给 Agent 一个查资料的能力（读新闻、读规则文本、读财报），再让它推理，是最可能见效的改法。这是 BootLoops 研究里单项最大效应的果实。
2. **把“主题轮”的推理用广。** 能源轮证明 Agent 能推出新种类（数据中心要电），但它只在 3 个玩家身上用了这个推理。下一回，Agent 应该先判断“这轮是什么主题”，再把主题套到所有相关玩家身上，而不是一个一个看习惯。
3. **别想多。** Agent 想多了丢 3 道。规则是：没有强理由偏离习惯时，就猜习惯。习惯的命中率是 57%，偏离要拿出证据。
4. **把握要诚实。** high 和 medium 的命中率一样（38% 对 39%），说明 Agent 的把握分级没起作用。把握应该按证据强度分：习惯强、线索连续的才算 high；全靠推测的算 low。
5. **NVDA 和台积电这类历史薄的玩家要单独处理。** 它们的动作没有习惯可循，Agent 应该更多看外部事件（合规、调查、订单），而不是翻历史。

## 诚实说明

- 泄漏风险：Agent（本子代理）从训练和上下文里知道 2025–2026 年的事。预测时只用上下文文件里的前缀，不用这些知识。能源轮的三道能源是推理得出的（数据中心要电），但不能完全排除潜意识里知道“这是能源轮”的影响。报告如实记下这一点。
- 分数说明：83 道题太少，分不出小幅改进是真变好还是运气。30 对 23 的差距（7 道）是实实在在的，但要确认 Agent 真的比简单规则强，需要更多题目。
- 原型不改 live 模型。预测、答案、上下文、报告都在 `runs/agent-prototype-2026-11-21/` 和 `design/agent-predictor-prototype.md`，分支 `loop/agent-prototype`，没有合进 main。
