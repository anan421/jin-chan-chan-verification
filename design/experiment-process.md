# 实验与过程设计（2026-11-22）

## 原则
- 每个实验都有对照组，并行跑。没有对照组，就没有结论。
- 每轮只改一个变量。对照组和实验组之间，只差那一个变量。
- 假设、证伪条件、决策规则，实验前写下来。跑完不改。
- 分数要诚实量出来：量噪声、选和估分开、按最弱一环打分。
- 过程本身也要做实验。定期测一测这个方法本身靠不靠谱。

## 实验结构（每轮）
1. 假设（实验前写下来）：改什么、为什么、多多少。证伪条件写清楚。
2. 对照组：当前最好的方法（先查资料），并行重跑，同一套题、同一套纪律、同一批预测员池子。
3. 实验组：1–3 个新方法，每个只改一个变量。
4. 随机分派：预测员随机分到对照组和实验组。题目顺序打乱。
5. 盲测：预测员不知道自己是对照组还是实验组。只按给的方法做。
6. 测量：总分（配对比较）、分项（种类、玩家、轮次）、噪声、把握分级准不准。
7. 决策规则（实验前写下来）：实验组要超过对照组多少才算赢（超过噪声带）。赢了就变成新底子（棘轮），输了就丢掉并记原因。
8. 复盘：写报告（分数 + 原因 + 学到了什么 + 下一步）。下一轮方向从复盘定。

## 对照组为什么要并行
- 预测员本身有方差。同一方法、同一轮，不同预测员能差 10 道（日期修正线能源轮 0/10，先查资料 10/10）。
- 拿新方法的分数和老 60/83 比，混了两个东西：方法差 + 预测员差。并行对照组把预测员差去掉，只剩方法差。
- 对照组和实验组用同一批预测员池子、同一时间跑，比较才干净。

## 噪声怎么量
- 先量对照组的噪声：对照组跑 3 次（3 套独立预测员），看分数的 spread。spread 就是噪声带。
- 实验组跑 1 次。超过对照组噪声带的上沿，才算赢。
- 比如对照组 3 次是 58、60、61，噪声带是 ±2。实验组要 63 以上才算赢。62 不算赢，是噪声。
- 噪声带一量出来就写下来，以后每轮都用它当标尺，不用每次重跑 3 次。

## 选和估怎么分开
- 题集分成两半：A 集用来选赢家，B 集用来报分数。赢家在 A 集上选出来，分数在 B 集上量。
- 83 道太小，分不开（41/42 一半的噪声比信号还大）。题集长到 140 道以上再分。
- 在题集长到 140 道之前，诚实标注：分数是在选过方法的同一套题上量的，是上限，不是真实水平。

## 最弱一环怎么打分
- 不只报总分。每个种类、每个玩家、每个轮次的分项分数都报出来。
- 最弱的一项单独列出来。方法好不好，看最弱的一项，不只看总分。
- 比如总分 60/83 但资本开支 2/5、台积电 0/3，这个方法就是有弱项。

## 过程本身的实验（测一测方法本身）
定期（每 3 轮）做一次，测这个实验方法本身靠不靠谱：
1. 单轮隔离真的防漏题吗？故意给一组预测员漏一道答案，看漏题检查能不能抓出来。抓不出来，隔离是摆设，改检查。
2. 预测员池子影响分数吗？同一方法、两套不同预测员池子，分数差多少。差得比噪声大，说明“方法分数”其实是“池子分数”，换池子要重测。
3. 题目顺序影响分数吗？同一方法、题目顺序打乱，分数变不变。变了，说明有顺序效应，题目顺序要固定随机。
4. 把握分级准吗？高把握的预测是不是真的更准。几轮下来高把握还不准，把握分级就别用了。
5. 打分脚本对吗？每轮分数由第二套独立脚本重算。两套对不上，停下来修脚本。
6. 题集量的是什么？把题按难度分三档，看方法的优势是不是只集中在容易的题上。是的话，方法没有真的变强，只是会做容易的题。
7. instruction 措辞影响分数吗？同一方法、两种措辞，分数差多少。差得比噪声大，方法就是脆弱的，措辞要固定下来。

测出来的结果写进过程设计里，过程本身跟着改。过程也是迭代的一部分。

## 过程流程（每轮）
1. 提议：写假设 + 证伪条件 + 决策规则。跑之前写好。
2. 设计：对照组 + 实验组、随机分派、盲测、测量计划。跑之前写好。
3. 建：题目文件、事实库、打分脚本。先让对照组复现底线（60/83），再跑实验组。
4. 跑：预测员并行工作，单轮隔离，不漏题。协调员不猜（它知道答案）。
5. 打分：脚本打分。第二套脚本独立重算。配对比较。
6. 审计：漏题检查、日期违规检查、样本小的说明、诚实记录。
7. 复盘：写报告，提交 main。分数 + 原因 + 学到了什么 + 下一步。
8. 决策：按跑之前写好的规则，赢了就变新底子（棘轮），输了就丢掉记原因。不凭感觉改。
9. 循环：下一轮方向从复盘定。不按预定计划走。

## 正在跑的第一轮（前瞻指引）怎么按这个过程改
- 加并行对照组：先查资料（不加前瞻指引）用新的一套 13 个预测员并行重跑，和实验组同一批池子、同一时间。比较用配对，不用老 60/83。
- 噪声带：这轮先量对照组跑 1 次的分数，同时记下来。下一轮开始，对照组跑 3 次定噪声带。
- 其余纪律不变（单轮隔离、方法文件跑之前写定、打分脚本先复现底线）。
