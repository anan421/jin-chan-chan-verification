# 拟合层设计：从占位参数到估计权重

状态：设计稿，已建成冒烟版。写于 2026-11-21 晚。

## 一、为什么需要拟合层

回测可以量化预测命中率（M1–M5）。回测不能估计权重。收益函数的权重现在全是占位值。w_hp = 1.0、w_gold = 1.0、c_lever = 5.0、c_rule = 10.0、w_pos = 1.0、temperature = 1.0。这些值没有任何证据。占位参数跑出的回测只能说明管线能跑。它不能说明模型对。拟合层补这个缺口。它从已记录的动作里估计权重。方法是显现偏好。玩家实际走的动作揭示了他们的收益排序。拟合层把这个排序变成权重。

## 二、拟合方法

### 决策

拟合窗口内每轮每名在场玩家是一条决策。在场指该轮有记录动作。状态用 `backtest.chain_state` 从该轮之前的前缀链出。不给未来信息。首轮没有前缀。首轮的决策没有信息。首轮排除在外。候选种类是前缀里出现过的语义种类。它减去该日期被禁的种类。口径与 `backtest.py` 相同。`fit.py` 用 `kind_of()` 读 `semantic_kind`，缺失时回退 `action_kind`。`unknown` 不是动作。不进候选集。记录种类为 `unknown` 的 move 不进拟合。它的真实种类未知。无法当监督信号。它仍正常折进状态链。状态链不读种类。别人固定在记录种类上时。`unknown` 种类的期望增量仍进均值。与 `backtest.py` 的 `semantic_expected_deltas` 口径一致。期望增量 `exp(pid, kind)` 取自前缀。它用 `predict.expected_deltas` 与 `make_expectation`。

### 特征

别人固定在记录动作上。别人走记录种类的期望增量。玩家 i 试候选种类 k。排名用 `predict.ranks_of`。特征是五项。

- f_hp(α) = (hp_after)^α − (hp_before)^α。hp_after 是按当期规则上下界 clamp 后的血量。hp_before 是轮初血量。α = 1 时 f_hp = dHP。α = 1 恰为 v1。
- f_gold = dgold。
- f_lever = 1 当 gold_after < 0。否则为 0。
- f_rule = 0。本版合法动作的合规成本为 0。
- f_pos = 排名前 − 排名后。别人按记录动作走。玩家 i 走 k。

效用对特征是线性的。φ = (f_hp, f_gold, −f_lever, −f_rule, f_pos)。u = w · φ。w = (w_hp, w_gold, c_lever, c_rule, w_pos)。两个惩罚项的负号折进 φ。感知机更新是标准形式。w += η · weight · (φ(k*) − φ(k_pred))。直接对原始 f 更新会把 c_lever 推反方向。这一点写清是为了防错。

### 感知机

权重初始化为占位值 (1, 1, 5, 10, 1)。每轮决策：argmax 不等于记录种类时更新。η = 0.1。weight 是该决策的折现权重。更新后把 w 的负分量截到 0。每 epoch 结束把 w 归一化到单位 L2 范数。定标尺的理由：效用乘正数不改变 argmax。不定标尺，权重大小没有意义。30 个 epoch。时间顺序跑。报告的权重是 epoch 平均权重。平均对象是 30 个 epoch 末的归一化向量。平均后再归一化一次到单位 L2 范数。

### 分档

五类玩家各拟合一份。另加一份全席共享权重做参照。共享拟合是全局参数的来源。`predict.py` 与 `backtest.py` 只读全局参数块。分档权重记在 `player_types` 里。它们现在不用。它们等 `predict.py` 支持按类取参时再用。

### 首发种类下限

新种类首发的轮次不可预测。它的种类不在前缀里。它不在候选集里。它自动记一次违规。感知机对它不更新。没有合法对照可以学。全窗口 540 条决策里有 40 条是首发。违规率有约 7.4% 的结构下限。读违规率时要扣掉这一项。真实 trace 上这个下限高得多。拟合窗口 S1–S3 共 31 条决策。13 条是首发。结构下限 41.9%。只剩 18 条是权重能影响的决策。见附录真拟合一节。

## 三、折现因子设计

决策权重 = γ^(R−r)。r 是该决策的全局轮序。跨赛季按时间排。0 起。R 是拟合窗口内最后一轮的轮序。语义：拟合里的新近加权。旧证据权重低。γ = 1.0 为等权。这是当前行为。γ 网格是 {0.90, 0.95, 0.98, 1.0}。α 与 γ 联合网格搜索。选违规率最低者。违规率按折现权重加权。平局向 α = 1、γ = 1 靠。模型更简单。

多步延续值折现是未来扩展。它不在本版实现。写清区别：本版的 γ 折现的是拟合证据的新近程度。它不折现未来奖励。未来扩展是另一件事。它要把多步回报折进效用。它需要新的特征项与新的验证。不要把两者混为一谈。

## 四、血量边际递减设计

幂形式：f_hp(α) = (hp_after)^α − (hp_before)^α。α = 1 时恰回 v1。α < 1 时血量边际递减。血量越低，同样一点血量越值钱。

为什么用幂不用对数。两条理由。第一，hp = 0 无奇点。对数在 0 处无定义。血量归零是正常状态。对数形式要额外处理 0。第二，α = 1 严格还原 v1。幂形式在 α = 1 时就是线性 dHP。对数形式没有这个性质。

举例。α = 0.5 时。90→80 的代价是 √90 − √80 = 0.5426。40→30 的代价是 √40 − √30 = 0.8473。同样掉 10 点血。低血量时贵 56%。α = 1 时两者都是 10。没有区别。

金币项保持线性。这是当前假设。金币边际递减是未来扩展。它要新的参数与新的证据。本版不做。

## 五、不确定度

Bootstrap。B = 50。按轮重采样。整轮一起抽。保留轮内相关。轮内 18 名玩家的决策互相影响。按决策重采样会打断这种相关。(α, γ) 固定在选定值。每次重拟合 w 与 τ。重拟合用原始折现权重。轮序权重不随重采样改变。报告每权重均值、标准差、5%/95% 分位。还报权重为 0 的重拟合占比。占比高说明该权重不稳定。它在多数重采样里被截到 0。τ 也报同样的分布。随机种子固定。默认种子 20261121。结果可复现。

## 六、验证协议

Walk-forward。S1–S3 拟合。S4–S5 测试。拟合窗口内的违规率是样本内指标。它不得当校准。样本内拟合优不代表样本外能预测。真正的检验是 `backtest.py`。它用 v1 投影文件跑 hold-out M1–M5。它对照随机基线。裕度是 10pp。命中率低是机制错。改模型不改数据。改数据掩盖模型错误。是造假。

### 采用门控（hold-out gate，2026-11-21 第 2 轮定稿）

拟合模型升 live（写进 `rules/payoff-model.json`）的唯一条件是 hold-out 门控。三条同时满足才能升版。写死，不可口头放宽。

- (a) hold-out（S4–S5）上至少三项 M1–M5 优于占位。优于指严格大于。平局不算赢。输赢按同一测试窗、同一 M1 分母口径逐项比较。
- (b) M1 高于随机基线至少 10pp。M1 取 hold-out 上的拟合值。基线取同一回测报告里的 M1 随机基线。
- (c) M2、M3 高于 50%。两者都要高于 50%。只高一项不算。

样本内违规率只作诊断，不作采用依据。拟合窗口违规率再好也不算。每次拟合附 hold-out 对照表（拟合对占位，五项并列，带每项差值与输赢）。无对照表不得升版。没有对照表的拟合报告，其 `adoption_recommendation.meets_rule` 一律为 false。门控在 `fit.py` 里实现（`evaluate_holdout_gate`，`--holdout-fitted` 与 `--holdout-placeholder` 两个回测报告作输入）。分母不一致（m1_n 不同）时门控拒绝比较，拟合运行直接报错退出，不写采用建议。

本门控取代附录“采用规则修订”里 fit02 的弱口径（“只有 hold-out 优于占位才采用”，未写死几项、多大幅度）。弱口径已废止。以本节为准。v3 与 fit02 按本门控的评估见第七节。

违规率不是数据质量检测。负向控制已经证明这一点。broken fixture 与 ok fixture 的违规率完全相同。S1–S3 窗口都是 0.732026。全窗口都是 0.822222。真拟合任务里用语义版 `fit.py` 与占位 v2  payoff 按同一协议重跑。结果逐项相同。控制复现。原因有两条。第一，broken fixture 的两处改动都在 S4–S5。S1–S3 窗口里根本没有坏数据。第二，全窗口里也只有两处改动。S4R1 只改了日期与规则版本。血量上下限相同。禁种为空。决策不受影响。S5R1 把 openai_mar26 换成 overseas_rental。两者都是首发种类。两者本来就都记违规。换一个等于没换。数据质量是 `check.py` 的事。C2、C3、C5 抓这类错误。拟合层不负责。

## 七、结构断点重拟合触发 T1–T5

触发条件写死。满足任一条就重拟。

- T1 玩家换 CEO。例如 NVDA Kress、苹果 Ternus。该玩家所在类用换帅后窗口重拟。报换帅前后权重。换帅改变该类玩家的收益排序。旧权重不再适用。
- T2 规则版本变。新 RV 生效。用新版本下窗口重拟。旧权重标 stale。规则改变动作空间。旧权重是在旧动作空间上估计的。
- T3 回测命中率掉。任一 M1–M5 裕度低于 10pp。`threshold_verdict` 为 below_threshold。报警“模型过期，须重拟”。只报警不自动重拟。与预测层第十项定夺一致。低于阈值只报告不自动改。
- T4 每赛季结算后例行重拟。该季数据完整且已验证。赛季是自然的断点。数据完整才能进拟合。
- T5 trace 重抽取或 data.json 对账修订。旧拟合作废。拟合所用的 trace 已不存在。重拟。

每次重拟写一条 refit 记录。字段：触发器、日期、旧模型版本、新模型版本。`payoff-model.json` 的 version 每次拟合加一。另设 fit_id。fit_id 标识这次拟合。格式是 `fit-<日期>-<序号>`。拟合输出文件里的 fit 块写同样的 fit_id。

每次重拟的采用都过第六节的 hold-out 门控。触发器只决定“重拟”，不决定“采用”。重拟后不满足门控的，live 不动。拟合输出只存运行目录。

## 八、诚实边界

Fixture 拟合不是校准。Fixture 是合成数据。它的动作不是按收益函数生成的。冒烟结果已经说明这一点。共享拟合违规率 0.732026。占位权重初值的违规率是 0.7092。拟合后的权重在样本内还不如初值。权重塌缩了。w_hp、w_gold、w_pos 全是 0。c_rule 是 0.9999。效用几乎是常数。预测退化成首候选规则。Bootstrap 也塌缩。w_hp 为 0 的重拟合占比是 1.0。这不是拟合器的 bug。合成恢复测试已经通过。数据按已知权重生成时。拟合器恢复出权重。余弦相似度 0.917。违规率 0.005。拟合器本身正确。Fixture 数据里没有这个效用族能解释的信号。这与占位参数下 M1 低于随机基线是同一件事。

v2 效用已进 `predict.py`（2026-11-21 晚，第二件）。`predict.py` 的 `utility()` 是 v2 式。α = 1、γ = 1 时严格还原 v1。γ 只做拟合时新近加权。单步预测不应用。v1 投影仍是 `backtest.py` 用的桥。它是 α = 1、γ = 1 下单独拟合的权重。它不是 v2 权重的换算。v2 权重在 α ≠ 1 时不能直接代入 v1 线性式。真拟合里 v1 投影与 v2 共享拟合分叉了。v2 共享违规率 0.709677。v1 投影 0.83871。比占位还差。只看一个会误判。两个都报。

Lean 一侧不受影响。`Dynamics.lean` 不动。拟合层只改 Python 侧的收益权重。它不改转移关系。不改不变量。不改证明。

金币线性与合规成本 0 是当前假设。c_rule 不可识别。f_rule 恒为 0。它的梯度恒为 0。它只随归一化移动。它的拟合值没有信息。不要解读它。
