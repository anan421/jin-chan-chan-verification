## 关键数字（本轮只看这几个）

每批（C1–C3、E1–E2）各算：
- 总分 T：13 道题猜中几道。
- 数据中心子分 D：3 道题猜中几道（q30、q31、q32）。
- 资本开支子分 C：10 道题猜中几道（q10–q19）。
- 两向错猜数：
  - X：数据中心题猜成资本开支，有几道（0–3）。
    这是本轮最关键的错猜方向：第 8 轮数据中心全错，
    主因就是看到花钱信号就猜资本开支。
  - Y：资本开支题猜成数据中心，有几道（0–10）。
    这是界限规则的反向代价：规则不能把资本开支题翻成数据中心。
- 界限引用率 B（实验组）：13 道聚焦题的预测里，
  写明用了界限规则第几步（或写明没用）的有几道。
  机械口径：推理里写出“地方是什么（或没有地方），数字是什么（或没有数字）”
  这句话（界限规则第 5 步的要求），才算引用。
  内容对不对，是审计的事。

再算两组汇总：
- 对照组总分平均 M_TC、差距 S_T = max − min（噪声带）。
- 实验组总分平均 M_TE。
- 数据中心子分平均 D_C、D_E，差距 S_D = 对照组 3 批 D 的 max − min。
- 资本开支子分平均 C_C、C_E。
- 两向错猜平均 X_C、X_E、Y_C、Y_E，差距 S_X = 对照组 3 批 X 的 max − min。

**实验组数据中心子分期望：每批 2–3/3。**
依据：第 6 轮实验组（3 条规则包）在干净的数据中心题上是 2/2 两批。
本轮只测界限这一条，q31、q32 应能守住，q30 是修干净后第一次计入，
期望 2–3/3。掉到 1/3 以下，说明界限规则单独不起作用。

**实验组资本开支子分期望：每批 9–10/10。**
依据：第 8 轮实验组资本开支 10/10。界限规则第 3 步
（只给数字、没点地方 → 资本开支）与前瞻指引步骤不冲突，
不应该把资本开支题翻成数据中心。掉到 8/10 以下，
说明界限规则在资本开支题上帮了倒忙。

**两向错猜期望：对照组每批 X = 2–3 道，实验组 X = 0–1 道；
Y 两组都是 0–1 道。**
依据：第 8 轮数据中心 3 道全错，错猜方向主要是资本开支。
界限规则第 2 步（点了地方 → 数据中心）应把 X 压下来。
Y 在第 6 轮只出现过 1 次（对照组 q19 猜成数据中心），
界限规则不应让 Y 变大。

**实验组总分期望：11–13/13。**
增益主要来自数据中心（+2 道左右），资本开支不掉分。
净增益是正是负，本轮才知道。

**界限引用期望：** 实验组 13 道聚焦题预测里，至少 80% 写明界限步骤。
审计时数。

## 证伪条件（跑之前写下来）

出现以下任何一条，说明界限规则单独不起作用：
1. 实验组数据中心子分平均 D_E < 1/3（3 道题平均猜中不到 1 道）。
2. 实验组总分平均 ≤ 对照组总分平均（M_TE ≤ M_TC）。
3. 实验组资本开支子分平均 C_E < 8/10（界限规则把资本开支题翻坏了）。
4. 实验组两向错猜没变好：X_E ≥ X_C（数据中心还是照样猜成资本开支），
   并且 Y_E > Y_C（资本开支反而更多猜成数据中心）。
5. 审计发现实验组的增益来自漏题（事实就是本轮动作本身），而不是规则。
6. 实验组界限引用率 B < 50%——规则根本没被执行，
   分数高也不能算到规则头上。

## 决策规则（跑之前写下来，跑完不改）

记：T_C1、T_C2、T_C3 = 对照组 3 批在 13 道题上的总分；
S_T = max(T_C) − min(T_C)；M_TC = (T_C1 + T_C2 + T_C3) / 3；
T_E1、T_E2 = 实验组 2 批的总分；M_TE = (T_E1 + T_E2) / 2；
D_E = 实验组数据中心子分（3 道）的平均；D_C = 对照组数据中心子分平均；
C_E = 实验组资本开支子分（10 道）的平均；
X_C、X_E = 两组数据中心题猜成资本开支的平均道数；
Y_C、Y_E = 两组资本开支题猜成数据中心的平均道数；
B = 实验组界限引用率（审计数）。

**进基线（界限规则帮上忙）：** 以下五条同时成立：
- (a) M_TE − M_TC > S_T（总分增益超过对照组噪声带）；
- (b) D_E ≥ 2.0/3，且实验组每批 D ≥ 2/3（数据中心确实修好了，不是单批运气）；
- (c) C_E ≥ 9/10，且实验组每批 C ≥ 9/10（资本开支没掉）；
- (d) X_E ≤ X_C − 1（数据中心错猜成资本开支确实少了至少 1 道），
  且 Y_E ≤ 1.0（资本开支错猜成数据中心平均不多于 1 道）；
- (e) B ≥ 80%（规则确实被执行了）。
- 进基线：界限规则成为基线的一部分
  （收紧后的查资料规则 + 前瞻指引步骤 + 界限规则）。
  第 10 轮在这个基线上测下一条（角色扮演 + 前瞻指引）。

**不进基线（界限规则没帮上忙）：** 以下任何一条成立：
- M_TE ≤ M_TC（净总分没正）；
- D_E < 1/3（数据中心还是没修好）；
- C_E < 8/10（资本开支被翻坏了）；
- B < 50%（没法证明是规则起的作用）。
- 不进基线：界限规则不进基线，回到只用收紧后的查资料规则 + 前瞻指引步骤。
  报告里按题写清为什么（哪道题还是猜成资本开支、地方信号是缺了
  还是被花钱信号盖住了）。第 10 轮重新诊断，或测下一条单规则。

**有帮助但不进基线（混合结果）：** (b)(c)(d)(e) 过了，但 (a) 不过
（数据中心修好了、资本开支没掉、错猜方向对了，
但总分增益没超过对照组噪声带 S_T）。
- 结论：界限规则在数据中心题上帮了忙，但在 13 道题上量不到
  超过噪声的总分增益。规则不进基线，记为“有帮助、待更多数据中心题复测”。
  下一步是补数据中心题（S6 新事件），不是直接采用。
  13 道题太小，一道题就是 1 分，零结果不等于规则没用，
  分题的规律（哪道动了、哪道没动）才是主要证据。

**泄漏守卫：** 审计发现任何一道实验组猜对的题用了漏题事实
（包括抄界限文档例题里的事件数字），
去掉那道题重算分数；如果结论依赖于它，结论作废。

## 已知的局限（写下来，不藏着）

1. **样本很小。** 聚焦集只有 13 道题，数据中心只有 3 道。
   一道题就是 1 分，胜负线（超过噪声带）相对期望增益（+2 道）很高。
   零结果不等于规则没用，分题的规律才是主要证据。
2. **数据中心子分是上限。** 3 道题全是规则照着设计的题，
